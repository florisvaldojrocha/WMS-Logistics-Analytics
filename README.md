# WMS Logistics Analytics

Projeto de Analytics aplicado a uma operação logística de distribuição, transformando dados operacionais em indicadores, análises e informações para apoio à decisão.

## Objetivo

Transformar dados operacionais em informações gerenciais para identificar:

- desempenho do SLA;
- volume de pedidos;
- pedidos atrasados;
- tempo médio de processamento;
- períodos com maior concentração de atrasos;
- áreas e turnos críticos;
- principais ocorrências associadas aos atrasos.

## Problema de negócio

Em operações logísticas, controlar apenas o volume de pedidos não é suficiente para identificar gargalos operacionais.

O projeto busca responder:

> Onde estão os atrasos, quando eles acontecem e quais ocorrências estão associadas ao problema?
