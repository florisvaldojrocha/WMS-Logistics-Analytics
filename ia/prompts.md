# Prompts de IA — WMS Logistics Analytics

## Objetivo

Este documento registra os prompts utilizados durante o desenvolvimento do projeto WMS Logistics Analytics.

A IA foi utilizada como apoio à análise, documentação, estruturação técnica e construção do portfólio.

---

## 1. Definição do projeto

### Prompt

> Atue como consultor de dados e logística. Ajude a estruturar um projeto de análise de dados aplicado a uma operação de WMS, utilizando Excel, Power Query, Power BI, DAX, Python, SQL e Databricks. O projeto deve transformar dados operacionais em indicadores gerenciais e identificar causas de atrasos.

### Objetivo do prompt

Definir o escopo e a arquitetura inicial do projeto.

---

## 2. Análise dos indicadores

### Prompt

> Analise os indicadores de uma operação logística considerando volume de pedidos, pedidos atrasados, percentual de SLA e tempo médio de processamento. Identifique padrões relevantes por período, turno, área e ocorrência.

### Objetivo do prompt

Apoiar a interpretação dos resultados gerados pelo Power BI, Python, SQL e Databricks.

---

## 3. Identificação das causas dos atrasos

### Prompt

> A partir dos dados de pedidos atrasados, analise a frequência das ocorrências e o tempo médio de processamento associado a cada ocorrência. Diferencie problemas de maior frequência de problemas de maior impacto operacional.

### Objetivo do prompt

Separar frequência de ocorrência e impacto operacional para apoiar a análise gerencial.

---

## 4. Documentação técnica

### Prompt

> Transformar a estrutura técnica do projeto em uma documentação clara, explicando o uso de Excel, Power Query, Power BI, DAX, Python, Databricks e GitHub, bem como a integração dessas tecnologias no fluxo de Analytics.

### Objetivo do prompt

Produzir documentação profissional do projeto.

---

## 5. Portfólio profissional

### Prompt

> Estruture a apresentação de um projeto de Analytics aplicado à logística para utilização em GitHub, portfólio e LinkedIn. Destaque o problema de negócio, arquitetura, tecnologias utilizadas, indicadores, análises realizadas e resultados.

### Objetivo do prompt

Transformar o projeto técnico em evidência profissional.

---

## Observação

Os prompts acima representam os principais prompts utilizados ou reconstruídos durante o desenvolvimento do projeto.

Quando um prompt não estiver disponível em seu texto histórico exato, ele é apresentado como uma reconstrução fiel da finalidade utilizada durante o desenvolvimento.
